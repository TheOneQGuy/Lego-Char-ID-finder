# Lego-Char-ID-finder
This is a tool to get character names for the MINIFIGCUSTOMISERPARTS_AUTOGENERATED.XML file and its variants (e.g. MINIDOLLCUSTOMISERPARTS_AUTOGENERATED.XML in TLM2). This file uses weird numbers (called hashes, e.g. -2138279224 for Iron Man Mark 6) to reference characters instead of the normal CD names (e.g. IRONMANMARK6) and was included in all Tt Games' LEGO games starting from LEGO Marvel's Avengers.

This files controls the customizer in these games, and for some games like LEGO Worlds and The LEGO Movie 2 Videogame, modifying it is necessary for being able to play as the character.

Note: This tool was created mostly by AI. But it is fully functional
